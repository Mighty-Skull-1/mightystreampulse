How to add to OBS Studio:

  1. Open OBS Studio or Streamlabs.
  2. Under Sources, click + (Add Source) and select Browser.
  3. Name it MightyStreamPulse Overlay.
  4. Paste the URL above into the URL field.
  5. Set Width to 1920 and Height to 1080 (or your stream canvas size).
  6. Check "Shutdown source when not visible" and click OK!
